# Jardín romántico para Isabella

Los archivos finales son:

- `Isabella-Jardin-Romantico.rbxl`, versión binaria recomendada.
- `Isabella-Jardin-Romantico.rbxlx`, versión XML de respaldo.

## Abrir en Roblox Studio

1. Descarga el archivo `.rbxl`.
2. Abre Roblox Studio.
3. Selecciona **Archivo → Abrir desde archivo**.
4. Elige `Isabella-Jardin-Romantico.rbxl`.
5. Presiona **Jugar** para recorrer el jardín desde el punto de aparición.

Si Studio no puede abrir la versión binaria, sigue los mismos pasos con
`Isabella-Jardin-Romantico.rbxlx`.

## Contenido añadido

- Entrada iluminada con una dedicatoria para Isabella.
- Inicio configurado directamente frente al recorrido romántico.
- Tres fotografías integradas directamente en el mapa como mosaicos.
- Marcos dorados y mensajes bajo cada fotografía.
- Corazones flotantes a lo largo del camino.
- Corazón de neón y dedicatoria final cerca del santuario.

Todo el contenido personalizado está agrupado en
`Workspace → Para Isabella`, por lo que puede moverse o editarse fácilmente.
Las fotografías no necesitan IDs externos de Roblox.
