# Análisis de requerimientos de WhatsApp

Presentación de siete diapositivas para la actividad formativa de la semana 1.

Antes de entregar:

1. Abre `Analisis_requerimientos_WhatsApp.pptx`.
2. Reemplaza `[ESCRIBE TU NOMBRE]` y `[ESCRIBE TU RUT]`.
3. Revisa el texto y ajústalo con tus propias palabras.
4. Exporta nuevamente a PDF si realizas cambios.

Para volver a generar ambos archivos:

```bash
npm install
npm run build
```
